# ✨ About

Hackwarts Hourglass is an AI-powered community skill-sharing platform where users exchange knowledge instead of money.

Inspired by the Hogwarts universe, every member becomes a wizard capable of teaching spells (skills) while learning new magical abilities from others.

The platform intelligently matches learners with mentors using AI recommendations, encourages community engagement through a Galleon credit system, and rewards contribution rather than transactions.

## 🧙 Wizard Profiles

- Personalized wizard profiles
- Hogwarts-inspired interface
- Skills Offered (Tutor)

- Reputation & Ratings

## 🎩 AI Sorting Hat Matching

Our AI-powered "Sorting Hat" recommends the best mentors based on:

- Skills
- Learning interests
- Community ratings
- Magical Synergy Score
- Personalized AI Match Alignment

## 🦉 Owl Post

- Send requests
- Community communication
- Mentor invitations

---

## 🏆 Community Credits

Instead of money, the platform uses **Galleons**.

- Teach → Earn Galleons
- Learn → Spend Galleons
- Encourage volunteering
- Reward active contributors

---

## 📅 Skill Exchange

- Request a mentor
- Accept exchanges
- Schedule learning sessions
- Track completed exchanges

---

## ⭐ Review & Trust System

After every completed exchange users can:

- Leave ratings
- Write reviews
- Build community trust
- Improve future recommendations

---

## 🏅 Leaderboards

Compete with fellow wizards by contributing to the community.

Leaderboard rankings are based on:

- Skills shared
- Community contribution
- Reviews
- Reputation

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Hackwarts.git
```

Move into the project

```bash
cd Hackwarts
```

Install dependencies

```bash
npm install
```

or

```bash
bun install
```

Start development server

```bash
npm run dev
```

or

```bash
bun run dev
```
